Database Architecture & Technical Hub

Architecture overview, JDBC components, and SQL verification queries

📚 JDBC Architecture & Core Interfaces

1. DriverManager: Manages JDBC drivers registered in the JVM. Uses DriverManager.getConnection(url, user, pass) to establish the socket connection to Oracle.

2. Connection (java.sql.Connection): Represents the physical session with Oracle. Manages transactions using setAutoCommit(false), commit(), and rollback().

3. PreparedStatement: Precompiles SQL statements on the Oracle database engine. Prevents SQL injection attacks, handles datatype casting, and optimizes repeated query execution.

4. executeQuery() vs executeUpdate():
• executeQuery(): Used for SELECT queries; returns a ResultSet.
• executeUpdate(): Used for DML (INSERT, UPDATE, DELETE); returns the integer row count affected.

5. ResultSet: A cursor pointing to rows returned by Oracle. Navigated via rs.next() with typed getters (rs.getInt(), rs.getString(), rs.getDouble()).

🔒 ACID Transaction Handling in Code

Implemented in PatientDAO 
conn.setAutoCommit(false); // 1. Begin atomic transaction
try {
    // 2. Delete dependent readings (Foreign Key cleanup)
    psReadings.executeUpdate();

    // 3. Delete parent patient record
    psPatient.executeUpdate();

    conn.commit(); // 4. Commit both operations atomically!
} catch (SQLException e) {
    conn.rollback(); // 5. Undo all changes if any error occurs
    throw e;
} finally {
    conn.setAutoCommit(true);
}
